# AI Code Review

## Goal

This guide explains how to accomplish the **AI Code Review** workflow using ProjectBrain.

**Commands Involved:** 1

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain diff review` | Explain code changes using LLM | diff |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain diff show
```

Follow the prompt.

### Step 2

Run:

```bash
brain diff review
```

Explain code changes using LLM

---

## Expected Outcome

After completing the **AI Code Review** workflow you should have all required outputs generated by the commands above.
