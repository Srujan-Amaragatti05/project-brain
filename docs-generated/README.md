# ProjectBrain Documentation

## What Is ProjectBrain

ProjectBrain is an integrated development tool designed to streamline repository analysis, code transformation, and diagnostic workflows.

## Key Capabilities

*   Automated repository analysis and summarization.
*   Intelligent diff generation and code explanation.
*   Seamless project health diagnostics.
*   Cross-platform code export functionality.
*   Integrated LLM performance testing.

## Core Workflows

1.  **Project Initialization & Analysis**: Initialize and generate summaries of existing codebases.
2.  **Change Management**: Review and explain changes using diff commands.
3.  **Diagnostic & Optimization**: Run project health checks and LLM integration tests.
4.  **Exporting**: Extract code or changes for documentation or external usage.

## Documentation Structure

The documentation is organized into categories covering commands, personas, and specialized use cases to facilitate rapid implementation.

## Command Categories

*   **diff**: `brain diff show`, `brain diff review`, `brain diff explain`
*   **export**: `brain export full-code`, `brain export file`, `brain export dir`, `brain export code-changes`
*   **project**: `brain project init`, `brain project analyze`, `brain project summary`, `brain project doctor`
*   **testllm**: `brain testllm test`

## Getting Started

1.  Run `brain project init` to configure your current directory.
2.  Execute `brain project analyze` to map your project structure.
3.  Utilize specific commands from the category list to manage your workflow.
