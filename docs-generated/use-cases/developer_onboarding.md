# Developer Onboarding

## Goal

This guide explains how to accomplish the **Developer Onboarding** workflow using ProjectBrain.

**Commands Involved:** 1

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain diff explain` | Explain a file or function | diff |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain project analyze
```

Follow the prompt.

### Step 2

Run:

```bash
brain diff explain
```

Explain a file or function

---

## Expected Outcome

After completing the **Developer Onboarding** workflow you should have all required outputs generated by the commands above.
