# First Time Installation

## Goal

This guide explains how to accomplish the **First Time Installation** workflow using ProjectBrain.

**Commands Involved:** 1

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain project init` | Initialize project-brain in the current directory | project |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain project init
```

Initialize project-brain in the current directory

### Step 2

Run:

```bash
brain project analyze
```

Follow the prompt.

### Step 3

Run:

```bash
brain project summary
```

Follow the prompt.

---

## Expected Outcome

After completing the **First Time Installation** workflow you should have all required outputs generated by the commands above.
