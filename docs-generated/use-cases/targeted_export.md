# Targeted Export

## Goal

This guide explains how to accomplish the **Targeted Export** workflow using ProjectBrain.

**Commands Involved:** 2

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain export file` | Manually add a single file to export | export |
| `brain export dir` | Manually add a directory to export | export |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain export file
```

Manually add a single file to export

## Expected Outcome

After completing the **Targeted Export** workflow you should have all required outputs generated by the commands above.
