# Change Review

## Goal

This guide explains how to accomplish the **Change Review** workflow using ProjectBrain.

**Commands Involved:** 1

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain export code-changes` | Export changed code between two git references | export |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain diff show
```

Follow the prompt.

### Step 2

Run:

```bash
brain export code-changes
```

Export changed code between two git references

---

## Expected Outcome

After completing the **Change Review** workflow you should have all required outputs generated by the commands above.
