# brain export full_code

## Purpose

Export entire codebase into structured file

---

## Syntax

    brain export full_code

---

## Parameters

_No parameters._

---

## Examples

- brain export full_code

---

## Outputs

- .brain/exports/full_code.txt

---

## Related Commands

- brain export dir

---

## Error Codes

_None_

## Notes

- Exports repository into AI-friendly format.

- Large repositories generate large export files.
