# brain project init

## Overview

Initialize project-brain in the current directory

---

## When To Use

This command is intended for **project** workflows.

---

## Syntax

```bash
brain project init
```

---

## Arguments

_No parameters._

---

## Examples

- brain project init

---

## Expected Outputs

- .brain/
- brain.yaml

---

## Error Reference

_None_

---

## Related Commands

- brain project analyze
- brain project doctor

---

## Operational Notes

- Safe to rerun.

---

## Edge Cases

- Existing files are preserved.
