# Project Onboarding

## Goal

This guide explains how to accomplish the **Project Onboarding** workflow using ProjectBrain.

**Commands Involved:** 2

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain project analyze` | Analyze repository structure using AST parsing. | project |
| `brain project summary` | Summarize the analyzed data | project |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain project init
```

Follow the prompt.

### Step 2

Run:

```bash
brain project analyze
```

Analyze repository structure using AST parsing.

### Step 3

Run:

```bash
brain project summary
```

Summarize the analyzed data

---

## Expected Outcome

After completing the **Project Onboarding** workflow you should have all required outputs generated by the commands above.
