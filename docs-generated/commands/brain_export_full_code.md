# brain export full_code

## Overview

Export entire codebase into structured file

---

## When To Use

This command is intended for **export** workflows.

---

## Syntax

```bash
brain export full_code
```

---

## Arguments

_No parameters._

---

## Examples

- brain export full_code

---

## Expected Outputs

- .brain/exports/full_code.txt

---

## Error Reference

_None_

---

## Related Commands

- brain export file
- brain export dir

---

## Operational Notes

- Exports repository into AI-friendly format.

---

## Edge Cases

- Large repositories generate large export files.
