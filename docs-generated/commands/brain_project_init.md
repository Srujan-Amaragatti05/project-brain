# brain project init

## Purpose

Initialize project-brain in the current directory

---

## Syntax

    brain project init

---

## Parameters

_No parameters._

---

## Examples

- brain project init

---

## Outputs

- .brain/
- brain.yaml

---

## Related Commands

- brain project analyze
- brain project doctor

---

## Error Codes

_None_

---

## Notes

- Safe to rerun.

---

## Edge Cases

- Existing files are preserved.
