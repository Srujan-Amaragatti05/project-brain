# Project Overview

## Goal

This guide explains how to accomplish the **Project Overview** workflow using ProjectBrain.

**Commands Involved:** 1

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain export tree` | Export repository tree structure into tree and JSON formats. | export |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain project analyze
```

Follow the prompt.

### Step 2

Run:

```bash
brain export tree
```

Export repository tree structure into tree and JSON formats.

---

## Expected Outcome

After completing the **Project Overview** workflow you should have all required outputs generated by the commands above.
