# Code Understanding

## Goal

This guide explains how to accomplish the **Code Understanding** workflow using ProjectBrain.

**Commands Involved:** 2

---

## Recommended Commands

| Command | Description | Category |
|----------|-------------|----------|
| `brain project analyze` | Analyze repository structure using AST parsing. | project |
| `brain diff explain` | Explain a file or function | diff |

---

## Recommended Workflow

### Step 1

Run:

```bash
brain project init
```

Follow the prompt.

### Step 2

Run:

```bash
brain project analyze
```

Analyze repository structure using AST parsing.

### Step 3

Run:

```bash
brain project summary
```

Follow the prompt.

---

## Expected Outcome

After completing the **Code Understanding** workflow you should have all required outputs generated by the commands above.
